# A股市场主线识别

输出当前市场主线，允许多个或暂无可确认主线，并解释每条主线及代表股的依据。10—20交易日看趋势骨架，近3—5交易日看题材接力与切换；“情绪”指情绪代表股。只做市场识别，不给仓位、买卖点或收益承诺。

## 1. 先执行环境准入

按名称在当前可用技能中发现并加载 `a-share-market-radar`；未注册时，在用户指定的技能目录中查找同名 skill 并读取其指令。按其流程判断环境，计算及题材确认按需读取它声明的参考资源，不假定安装路径。保持雷达为唯一环境分类入口，不在本 skill 另设牛熊阈值。

- 可复用同一交易日、同一盘中/收盘时点与口径完整的雷达结果，须能核验其分类确认状态、防御覆盖、切换待确认、关键缺项和来源。仅有“牛市”一句结论不能复用。
- 只有“牛市已确认”或“题材主导的结构性行情已确认”，且无防御覆盖、无切换待确认、关键风险已核验，才进入主线分析。结构行情不改变雷达的A整体大类。
- 熊市、当日熊候选触发防御、其他防御覆盖、环境未确认或关键环境数据不足，立即停止。局部涨停、熊市反弹、放量试探均不能绕过门槛。
- 不把风险未知当作风险解除。依赖文件缺失时明确说明无法执行准入，停止，不自行替换环境规则。

停止时只输出：截至时点、雷达环境/姿态、禁用或未确认原因、关键证据与缺项、按雷达重新启用所需条件。不列主线、候选方向或股票。

## 2. 风格 → 候选 → 确认 → 角色

准入通过后，读取[主线方法](references/mainline-method.md)，按以下顺序执行：

1. 分别判断大小盘、成长/价值、趋势/题材接力、集中/轮动。对照5日和20日表现，标注背离及切换迹象；风格不是筛掉其他方向的硬门槛。
2. 用行业、概念板块摘要发现候选，再获取候选成员及连续行情。单日涨幅榜、新闻和网络称号只用于发现。
3. 确认趋势主线或短线题材主线，比较板块之间的持续性、相对强度、联动广度、成交参与和承接。没有充分证据就列候选或“暂无可确认主线”。
4. 合并由同一批股票驱动的重叠主题；区分“已确认主线”“新主线候选”“原主线退潮”，不以新板块替换掩盖旧主线失败。
5. 对每条已确认主线选龙头、中军、情绪代表股。默认每个角色一只首选，必要时再列一只竞争者。允许兼任、角色空缺和争议，逐项解释。

龙头按主线风格判断市场领涨与带动，不等同于产业龙头；中军须有持续容量与趋势承接，不能仅凭市值；情绪股须有接力或高弹性标杆证据，不能仅凭连板高度。不得把最高涨幅、大市值、最高连板机械分配到三个角色。

## 3. 数据与执行边界

- 先核实可用行情工具（如通达信MCP、东方财富MCP、AKShare的实际接口），选一个主源；没有专用工具时联网公开数据兜底。不得宣称不存在的接口、缓存或历史能力已可用。
- 优先板块摘要，候选阶段再取成员及角色候选行情。不默认逐股下载全A历史；短线生态观察40交易日，收益和均线获取足够预热数据，详细预算与口径见方法参考。
- 用官方交易日历确定最近完整交易日，采用北京时间。盘中仅给临时结果，不把未收盘封板、未完成次日反馈或不完整成交额冒充收盘指标。
- 公告和官方披露核验代码、题材关联、催化及否认信息；行情公开数据应能追溯日期和范围。网络文章或热榜不能替代连续行情确认。
- 所有收益、排名和联动数据说明窗口、来源、样本及代理。成交额不等于净流入，龙虎榜不等于全市场资金构成，不凭这些推断机构或游资身份。
- 缺历史、封板记录或关键字段时按受影响的结论降级。准入缺项阻断整份报告；主线确认缺项阻断该主线确认；角色缺项只阻断该角色。不能编造或默认为零。
- 新增数值条件均为待验证默认值，不是已回测规律；不因当天行情临时改参数。不生成综合分数、胜率或预测概率。

## 4. 输出

先给结论，不罗列抓取过程。停止输出使用第1节的简式；通过准入后使用下列结构：

```text
【A股市场主线】准入通过 | 当前主线结论
截至：北京时间、行情交易日、收盘/盘中临时；主源、范围、缺项/滞后
环境：雷达整体环境、确认状态、风险姿态、结构、覆盖及待确认状态
市场风格：大小盘 | 成长/价值 | 趋势/接力 | 集中/轮动；5日与20日对照

主线总表：主线名称 | 趋势/短线/兼具 | 主导/并行 | 龙头 | 中军 | 情绪代表股 | 证据完整度

每条主线：
- 为什么是主线：持续性、相对强度、联动、成交参与、承接、催化；附数据与来源
- 龙头/中军/情绪代表股：名称＋代码、角色依据、关键数据、题材关联与来源
- 反向证据与竞争者：角色兼任/争议、主线内部或跨主线竞争
- 失效/降级条件：现有主线证据如何被破坏，哪些条件仍需观察

新主线候选：未满足的确认条件（无则省略，不填完整角色表）
原主线退潮：既有记录或连续历史证据、失效原因（无可核验前状态则不冒称曾确认）
方法限制：相关缺项、代理、未完成确认；方法尚未完成全市场历史回测
```

主线按证据排序，不固定凑数；并行主线可不分强弱。总表只放已确认主线；无确认时明确说明，并仅列有证据的候选。股票角色空缺写“暂无明确对象”，不拿弱证据补齐。证据完整度用高/中/低及原因，表示资料与确认的完整程度，不代表上涨概率。

## 5. 使用与验证

典型请求：“判断当前A股主线，列出每条主线的龙头、中军、情绪代表股和理由。”直接先执行准入，无需用户先手动运行雷达。

本 skill 按名称依赖 `a-share-market-radar`，不要求相邻安装。内部参考文件随自身目录保留；本地文件不等于已注册为全局可用技能。

修改后按[方法参考的情境验收](references/mainline-method.md#情境验收)核对行为，再运行 skill-creator 的 `quick_validate.py` 检查结构。格式校验与情境走查不等于实盘验证或历史回测。
