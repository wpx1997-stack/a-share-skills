# A股主线方法参考

环境分类、防御覆盖、结构确认和切换优先级由按名称加载的 `a-share-market-radar` 及其声明的参考资源定义，加载方式见本 skill 主文件。本文件仅定义通过准入后的风格、主线比较与股票角色；新增数值条件为待验证默认值，尚未完成历史回测。

## 一、先读市场风格

风格是多个独立观察轴，可以同时出现“大盘成长趋势＋小盘题材接力”，不要强迫归为一个标签。

| 维度 | 观察方法 | 解释限制 |
|---|---|---|
| 大小盘 | 复用雷达L/S的R5、R20及Size20，必要时补查中证500，核对各组上涨广度 | 指数受成分权重影响；小盘领先不证明炒差 |
| 成长/价值 | 优先同系列、同范围、同收益口径的成长与价值指数，比较5/20日相对表现；红利与银行另列 | 雷达G/D用于成长/防御代理，不能冒称纯成长/价值因子比较；无配套指数则标代理或未知 |
| 趋势/题材接力 | 趋势看10/20日多股上涨、成交持续和回撤承接；接力看联动、晋级、活跃池次日反馈和负反馈 | 只有大涨无接力生态时，不推断题材接力主导；两种风格可并存 |
| 集中/轮动 | 对照近5日与前阶段的领涨板块、成交占比及强势成员，看同一主线是否延续、分支是否扩散 | 同产业链扩散不必视为主线切换；频繁轮换且反馈差不称多主线共振 |

5日与20日方向一致时描述当前占优风格；不一致时描述近期变化，不能只凭一天宣称切换完成。若有确切持仓或资金身份披露可以引用，否则只描述价格、成交和交易反馈。

## 二、数据预算与统一口径

- 环境预算沿用雷达。新增板块部分优先主源现成的5/10/20日收益、成交占比、上涨广度、活跃池及40日生态摘要。
- 先扫描可用行业/概念摘要，初筛默认约8个候选；这是执行预算，不是主线数量上限。候选覆盖不全、遗漏新方向或证据冲突时定向补查，并披露扫描范围。没有全市场板块扫描能力时不得冒称全市场穷尽排名。
- 候选板块至少10个有效成员，与雷达样本门槛一致；默认沪深非ST、非停牌、具备相应价格历史的A股，北交所单列。上市初期无涨跌幅限制日不进入涨停接力比较。
- 板块收益和成员中位数分开报告；板块指数不能替代成员广度。优先可追溯板块指数，缺失时按固定成员日收益等权链式合成代理，并标“等权成员代理”。不同模式不静默拼接。
- R20需要至少21个有效日收盘；计算近5日各自的20日指标至少26个。默认约30交易日足够近期收益，生态摘要覆盖40交易日；MA60等指标须使用可靠摘要或另取充分预热，不用30日数据伪算MA60。
- 成员收益用一致复权口径；涨停、连板和交易状态用当日真实交易规则及官方未复权涨跌停价，剔除除权等机械影响。停牌、缺失和成员变动说明，不填零。
- 回溯窗口使用窗口起点可得成员并跟踪退出或缺失，不能只保留今天的赢家。无法取得历史成员时，注明“当前成员回看，有成员变动偏差”，历史持续性只能作候选证据，不能据此单独确认。
- 群体成交额按股票去重，成交占比的分母采用同范围沪深A股成交额。重叠主题占比不能相加；5日、20日成交占比使用各窗口成交额总和之比，不用不一致口径比较。
- 跨源冲突先核对交易日、复权、成员、ST范围及盘中/收盘时点，仍无法解释则保留冲突。可取得确定价格不代表已取得确定题材归属。

基本计算：`Rn=P_t/P_(t-n)-1`；板块相对市场收益 `RSn=(1+Rn(板块))/(1+Rn(M))-1`，M沿用中证全指。成员中位数与正收益比例分别在固定样本上算10日及20日窗口；相对收益为正仍可能绝对下跌，须同时核对绝对表现。

公开网页只有新闻、当日排名或少量代表股时，可发现候选但不能补齐整段历史。不得把网页摘要中的“主线”“龙头”称号当成自己的确认依据。

## 三、主线识别与比较

### 趋势主线

趋势确认需要以下条件同时具备：

1. 板块RS10、RS20均大于0，10日与20日成员收益中位数均大于0。
2. 至少3个不同成员在10日与20日均上涨，证明多股持续走强；同时列正收益比例，避免由少数权重遮蔽群体下跌。
3. 最近5个完整交易日中至少3日板块日收益高于M日收益。
4. 以上样本、历史和口径可核验；不存在仅靠一只个股、单日异动或事后重组成员解释强势的情形。

满足这些条件只是通过持续强势筛选。还须与其他候选比较持续性、参与广度、成交占比和分歧承接，判断是否承担当前市场主要强势方向；普通跑赢板块不自动成为主线。证据势均力敌可列并行主线，无法证明市场地位就保留候选。成交参与与承接影响强弱判断，不另设未经验证的成交额硬门槛。

### 短线题材主线

直接按雷达参考第三节计算固定群体的联动日、活跃池、已完成次日反馈及结构确认，不复制或另改阈值。某群体获得确认不意味着所有题材都获得确认。

确认后比较它在其他候选中的联动持续、活跃成员数量、晋级与负反馈、成交参与和分歧修复；短线主线应有群体延续和相对突出的市场地位。仅单股连板、一天集中涨停或新闻爆发只列候选。整体是牛市也不能豁免某条短线题材的持续确认。

同时通过趋势与题材证据的方向标“兼具”，不重复列两条。短线风格采用近3—5日变化，40日生态用于辨别阶段及此前负反馈，不能用较早活跃替代当前延续。

### 催化、重叠与排序

- 核查政策、订单、业绩、产品或供需事件的发布时间、发生时间和业务影响链；区分已发生事实、预期和未证实传闻。没有明确新催化可以说明，无需编一个故事。
- 先用主源成员和主题定义固定群体，再核查强势股业务。说明“实际业务关联”“已公告但尚未形成重要收入”“市场概念映射/业务否认”等差异。概念映射可能解释交易联动，但不能包装成真实业绩受益。
- 重叠比较使用成员交集、强势成员和成交贡献。若两个名称主要由同一强势股群与同一催化驱动，合并为上位主线并列分支。独立细分须有自身持续强势群、独立成交/联动证据，并独立满足确认条件。
- 按持续性、相对强度、联动广度、成交参与、分歧承接逐项比较，以可核验优势排序；不可把高度相关的收益、涨幅排名、相对收益当作三份独立证据。没有明显优势时不强行排序。

### 状态、承接与失效

观察最近实际分歧日：群体收益、上涨广度、成交变化、领涨股与中军回撤、后续已完成日的恢复及活跃池反馈。放量下跌、缩量回落、放量修复分别解释；无分歧历史写“承接尚未经分歧验证”。“带动”仅描述观察到的领先与跟随，不宣称因果。

- 新主线候选：证据正在形成，逐项列未满足条件，不预先授予完整角色。
- 趋势维持：每日重新核对趋势条件；任一条件失效即标“原主线待重确认”，不留在已确认总表。持续失效且群体弱化、核心股下跌扩散或承接失败有证据时标退潮，不把缺数据当退潮。
- 短线维持、常规降级、急性退潮与数据中断按雷达参考第三节处理；维持规则中的短期容忍不得绕过当前环境门槛。
- 无前状态时，不编造“昨日主线”或连续确认计数。只有可追溯的旧报告或按当时信息重建的历史证据才能称“原主线”。
- 环境新触发覆盖、进入熊市或切换待确认，整份主线报告撤回启用资格，按停止格式输出，不继续列个股。

每条主线给出具体失效条件，围绕其实际依据描述，例如相对强度转负且上涨广度收缩、活跃池负反馈达到雷达退潮条件、中军与跟随股连续承接失败；不凭空设置个股止损价。

## 四、角色选择

先从主线内收益领先、持续成交活跃、接力突出或高弹性成员筛选角色候选，再获取它们的连续行情及官方业务披露；不能先挑熟悉股票再反推主线。

| 角色 | 首选证据 | 常见反证与处理 |
|---|---|---|
| 趋势龙头 | 10/20日相对板块持续领先、较早启动、分歧时强势、走强时有多股跟随 | 单日补涨、只有绝对涨幅、主题身份存疑；带动未经验证时保留候选 |
| 短线龙头 | 同交易制度内接力地位、启动时序、分歧转强、活跃池跟随与次日反馈 | 一字板高度而交易承接不可观察、孤立连板、其他成员负反馈；不能自动确认 |
| 中军 | 近5/20日持续成交排名与群体成交贡献、可交易流动性、相对板块趋势与分歧稳定性、业务关联 | 大市值但低参与、单日天量后失速；成交大不证明机构持仓或承接良好 |
| 情绪代表股 | 连板/晋级、封板和炸板、换手与次日反馈、对板块情绪的领先响应；趋势中可用高弹性标杆 | 无封板历史不能声称封单稳定；仅高弹性无板块情绪联系时不强填 |

输出每个角色的名称与代码、至少两类不重复证据、比较窗口、主要反证及来源。角色候选势均力敌时给首选与一只竞争者并说明差异；完全缺乏区分依据时写“暂无明确对象”。

同股兼任时逐项说明，例如趋势领涨同时承担成交容量；不能因为已选龙头便复制为情绪代表。趋势行情可没有连板股或明确情绪股。行业龙头身份只说明业务地位，不授予交易角色。

连板、涨停数量和振幅按市场、交易板块及当日规则分组，核查ST、上市初期、停牌与规则调整。主板、创业板、科创板、北交所之间不直接按原始连板高度或日涨幅排名选龙头。分时先后、封单和炸板仅在实际可得时使用；仅有日K不能还原封板过程。

## 五、证据与来源

- 高：准入完整、该主线确认完成，关键角色资料齐全且无未决冲突。
- 中：主线仍有足够确认依据，但辅助指标使用明确代理、个别角色空缺或资料有非关键缺项。
- 低：主线关键历史、范围或冲突未解决；只列候选，不能以“低完整度”包装已确认主线。角色也可独立降级，不拖累其他已核实角色。

结论附近附可访问的来源链接；用户提供的数据注明文件及日期。行情、公告、政策的来源各自对应所支持的判断，不能用一篇综述为全部数值背书。官方来源也只证明披露事实，不证明本方法的有效性。

## 情境验收

以下是行为验收场景，使用模拟事实时明确标注，不能包装成当前实盘名单：

| 输入情境 | 必须得到的行为 |
|---|---|
| 已确认熊市但某板块多股涨停 | 准入停止，不输出方向与角色 |
| 牛市已确认但防御覆盖生效，或切换待确认 | 准入停止，解释风险优先 |
| 只有“牛市”结论，无日期/覆盖等记录 | 补执行雷达；补不齐则停止 |
| 牛市准入通过，某题材只爆发一天 | 只列新候选，不确认主线 |
| 趋势条件和市场地位成立，无连板股 | 可以确认趋势主线，情绪角色可空缺 |
| 同一股票领涨且持续承担成交容量 | 可兼任龙头和中军，理由分别给出 |
| 两个概念主要由同一强势成员群驱动 | 合并主线，避免重复成交额与确认依据 |
| 旧题材反馈恶化，新方向只有初次联动 | 按雷达降级旧题材，新方向仍为候选 |
| 仅当日排行榜与新闻，无历史/成员记录 | 不确认主线，不补造连续强势或角色数据 |
| 行情源收益冲突且复权/日期无法对齐 | 受影响结论保留候选，报告冲突 |
| 盘中封板但尚未收盘，次日还未发生 | 只报临时事实，不确认收盘封板或次日延续 |
| 不同交易板块分别有高连板和高涨幅 | 分组核验并综合带动，不按原始高度直接定龙头 |
| 公司公告否认热点业务，股价仍联动 | 明示业务否认及市场概念映射，不写成真实受益 |
| 当前成员回看历史，无法取得窗口起点成员 | 披露偏差，只作候选历史证据 |

创建阶段做结构校验和以上情境走查。历史有效性需另用当时可得成员、交易制度及公告时间逐日重放，校准与验证分开，评估主线持续性、覆盖率、切换延迟和退潮识别，不只挑成功案例；本次交付未执行该回测。
