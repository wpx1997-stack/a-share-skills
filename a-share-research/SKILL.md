# A股研究主调度

负责调用顺序和结果整合。判断方法、数据口径及风险规则以对应子 skill 为准。

按名称在当前可用技能中发现并加载下列子 skill；未注册时，在用户指定的技能目录中查找同名 skill 并读取其指令。找不到时停止对应步骤，不假定安装路径。

## 调用流程

1. **识大盘**：按 `a-share-market-radar` 执行，获得环境、风险姿态及市场结构。
2. **判国家队与拐点**：按 `a-share-turning-point` 执行，分别给出宽基ETF国家队增减持迹象、证据层级，以及顶部/底部0—100分和反转阶段。用户只问大盘时，完成本步后结束。
3. **研究赛道**：按 `a-share-mainline` 的准入规则检查雷达结果；通过后执行主线识别，比较赛道并说明理由。未通过时只报告大盘、国家队与拐点、停止原因和重新启用条件，不列方向或股票。国家队买入或底部高分不能代替雷达准入。
4. **选个股**：由主线 skill 在已确认主线中选择龙头、中军、情绪代表股并解释依据。没有确认主线时停在候选观察，不强行选股。

## 灵活调度

- 默认执行完整流程；指定赛道或股票时聚焦其主线地位与角色，不跳过大盘准入，也不预设它就是主线或龙头。
- 只问国家队、宽基ETF进出或市场拐点时，直接执行 `a-share-turning-point` 对应分析；涉及牛熊环境或风险姿态时补充雷达，不强制展开赛道、个股。
- 同一交易日、同一时点、口径完整且仍有效的结果与数据可复用。雷达与拐点共享可核验的指数数据，只补各自缺少的历史、ETF份额或净值；成交量、成交额、净申赎不混用。将完整雷达结果传给主线 skill，避免重复执行准入；过期或缺项时更新对应层级。
- 更新报告时先更新大盘及国家队与拐点，再更新主线与个股角色；环境、防御及主线准入以雷达和主线规则为准，国家队活动与反转阶段以拐点 skill 为准。允许“国家队买入但底部未确认”等并存结论，不合并成一个方向或总分。
- 拐点或ETF缺项仅降级对应结论，不自动否定已满足的雷达准入；环境准入的关键缺项仍按主线 skill 停止。

## 统一输出

整合成一份报告，避免重复粘贴子 skill 的完整输出：

1. **大盘**：截至时点、环境、风险姿态、准入结论和关键依据。
2. **国家队与拐点**：ETF增减持/调仓迹象、事实或推断层级及覆盖区间；顶部/底部原有0—100分、反转阶段、关键变化和缺项。国家队是否介入与市场是否反转分别回答。
3. **赛道**：市场风格、已确认主线及理由；候选与退潮方向分开。
4. **个股**：各主线的龙头、中军、情绪代表股，附代码、角色理由和来源；允许兼任或空缺。
5. **后续观察**：反向证据、失效条件、尚缺的确认条件。

按请求深度输出，仅看大盘或流程被拦截时省略赛道、个股；专项分析仅保留相关部分。保留子 skill 的证据完整度和方法限制，沿用拐点 skill 的原有评分，不另造综合分或换算胜率，不提供仓位或买卖点。
