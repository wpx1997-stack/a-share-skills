# A股研究主调度

负责调用顺序和结果整合。判断方法、数据口径及风险规则以对应子 skill 为准。

## 调用流程

1. **识大盘**：执行 [a-share-market-radar](../a-share-market-radar/SKILL.md)，获得环境、风险姿态及市场结构。用户只问大盘时，到此结束。
2. **研究赛道**：按 [a-share-mainline](../a-share-mainline/SKILL.md) 的准入规则检查雷达结果；通过后执行主线识别，比较赛道并说明理由。未通过时只报告大盘、停止原因和重新启用条件，不列方向或股票。
3. **选个股**：由主线 skill 在已确认主线中选择龙头、中军、情绪代表股并解释依据。没有确认主线时停在候选观察，不强行选股。

## 灵活调度

- 默认执行完整流程；指定赛道或股票时聚焦其主线地位与角色，不跳过大盘准入，也不预设它就是主线或龙头。
- 同一交易日、同一时点、口径完整且仍有效的结果与数据可复用，把雷达结果传给主线 skill，避免重复抓取；过期或缺项时更新对应层级。
- 更新报告时先更新大盘，再更新主线与个股角色；子 skill 之间出现冲突时，环境与防御以雷达为准，主线与角色以主线 skill 为准。

## 统一输出

整合成一份报告，避免重复粘贴子 skill 的完整输出：

1. **大盘**：截至时点、环境、风险姿态、准入结论和关键依据。
2. **赛道**：市场风格、已确认主线及理由；候选与退潮方向分开。
3. **个股**：各主线的龙头、中军、情绪代表股，附代码、角色理由和来源；允许兼任或空缺。
4. **后续观察**：反向证据、失效条件、尚缺的确认条件。

按请求深度输出，仅看大盘或流程被拦截时省略后续部分。保留子 skill 的证据完整度和方法限制，不新增评分、胜率、仓位或买卖点。
