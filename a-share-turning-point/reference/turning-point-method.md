# 评分计算与判断口径

本文件定义ETF国家队活动判断及四组反转评分的计算口径；[主文件](../SKILL.md)负责使用流程。活动判断标明事实或推断；顶部、底部各100分，不相减，不转换为预测概率。

## 输入与符号

`C/H/L/V`为收盘/最高/最低/成交量，窗口均为交易日。只用截至`t`已完成的数据。均线可含当天收盘，量能基准不含当前被比较的一段。采用价格指数，不能与全收益指数混算。

`s=+1`为底部，`s=-1`为顶部。`MA20[j]=mean(C[j-19..j])`。以完整日线计算，确认阈值为70分；确认日记实际满足全部条件的当天，不提前回填。

建议100日。窗口不足保持未知。主指数需覆盖参考交易日；伙伴缺报价不前填、不重分配权重。将主指数日期与伙伴及交易日历核对，防止缺失交易日被压缩为相邻日期。

## ETF国家队活动

异常成交优先看主要宽基ETF。`A`为成交额，`S`为总份额，`NAV`为单位净值，三者分别保留日期与单位。成交额衡量双向交易活跃程度，净申赎估算资金方向；不能用资产规模涨跌或成交额冒充净流入。

```text
VR1 = A[t] / mean(A[t-20..t-1])
VR5 = mean(A[t-4..t]) / mean(A[t-24..t-5])
F[t] = (S[t]-S[t-1]) * NAV[t]
F5 = sum(F[t-4..t])
```

`VR1≥2`或`VR5≥2`记巨量观察。`F`是按净值估算的净申赎金额，不是国家队实际成交金额，也不是全部二级市场买卖。份额折算、拆分及口径变化先调整；缺对应份额或净值时保持未知。申赎数据滞后时，不把旧份额和今天成交拼成同日信号。

先按同一指数汇总各产品的`F`，再看监测池合计；跨产品只能加金额，不能直接加份额。异常成交可由单只触发，但资金方向要检查同指数组及其他已覆盖产品是否有对冲赎回。池合计近零只说明未见整体明显净增减，不证明买卖者相同或没有国家队活动。

判断净申赎是否异常时，比较本期绝对净额与此前20日平均绝对日净额：单日比较`abs(F[t])/mean(abs(F[t-20..t-1]))`，5日比较`abs(F5)/(5*mean(abs(F[t-24..t-5])))`，按同指数组计算。达到2倍作为量级增强的观察口径，同时报告实际金额和占期初资产的比例；仅比值高但绝对金额很小，不给强推断。历史不足或基准为零时不硬算，降级说明。

巨量与异常正净额同时成立、监测池整体同向且没有明显迁移抵消时，可直接报“国家队大概率买入（强推断）”，无需先等底部确认。多日持续及不同指数同步是增强项，不是强制条件。负净额对应疑似减持/退出；停止净申购不是卖出，赎回得到股票也不等于已卖出股票。只有实名证据才能将主体标为已确认。

份额不变不能排除二级市场大额买入。只有巨量和收涨、没有净申赎或明确二级承接证据时，报方向未定，不把涨跌当买卖身份。公告或定期持仓只确认其覆盖区间；公告没说的产品、金额和未来交易不能补写。

以上是用于识别国家队行为的经验代理，不是“其他主体不可能这样交易”的排他证明。ETF介入与市场反转分开判断，不计入下列四组分数。机制边界参考[上交所ETF交易机制](https://etf.sse.com.cn/fund/learning/knowledge/c/5704300.shtml)。

## 位置：20分

1. 最近20个收盘找底部最低/顶部最高的日期`e`，并列取最近一日。这是当时已知极值，不要求未来确认。
2. 取`e`之前60个收盘的相反极值`A`；至少有60条前序记录。
3. `prior_move=s*(A-C[e])/A`。
4. `TR[j]=max(H[j]-L[j], abs(H[j]-C[j-1]), abs(L[j]-C[j-1]))`；`ATR20[e]=mean(TR[e-19..e])`。
5. `prior_move >= max(5%, 4*ATR20[e]/C[e])`得20分，否则0分。

波动率只用极值当日及以前，不用反转后的大涨大跌回头调整门槛。5%和4倍ATR是固定经验参数，不是理论最优值。

## 价格确认：50分

| 子项 | 计算 | 得分 |
|------|------|------|
| 均线位置 | 当日`s*(C[t]-MA20[t])>0` | 20，否则0 |
| 区间突破 | 最近3日有一天`s*C[j] > max(s*C[j-10..j-1])`，且今天在MA20正确侧 | 15，否则0 |
| 均线转向 | `s*(MA20[t]-MA20[t-3])>0` | 15，否则0 |

价格确认要求：当日处于MA20正确侧，且突破/均线转向至少一项成立，价格分至少35分。单独越过均线不构成确认。

子项同属价格组、彼此相关，不是三份独立证据。多等几日会减少部分假突破，也会错过转折，不能默认更严就更准。

## 扩散：20分

三只固定伙伴分别套用相同价格确认条件。每只对齐贡献`20/3`，无数据为0并计缺项，不提高其他伙伴权重。至少两只有完整窗口且同向确认，才允许确认市场反转。

伙伴不与主指数重复，日期精确对齐。没有伙伴只有单指数结论。指数有成分重叠，扩散代理不等于全A个股宽度，也不是独立样本。

## 量能：10分

以下任一项得10分，同时成立仍只得10分：

```text
s*(C[t]-C[t-1])>0 且 V[t]/mean(V[t-20..t-1]) >= 1.2
或
s*(C[t]-C[t-5])>0 且 mean(V[t-4..t])/mean(V[t-24..t-5]) >= 1.1
```

25日有缺量或基准均量≤0，该组未知不加分。这里计算成交量比例，不是成交额或ETF净流入。缩量不直接推断买盘枯竭，巨量不直接推断出货/扫货。

## 合成、缺项与失效

`raw_score=位置+价格+扩散+量能`。位置历史不足时总分未知；位置为0时`score=0`，表示不适用该侧新拐点，保留原始分与分项。位置20、主指数价格确认、至少两伙伴确认均满足时，`score=raw_score`；位置成立但其余门槛不足时`score=min(raw_score,69)`。达到70分且全部门槛满足，输出规则确认。

覆盖率另算：位置可算20、价格可算50、每只可算伙伴20/3、量能可算10。已知不触发不扣覆盖，未知不是已排除。覆盖率不能乘除总分，不能把缺项造成的低分理解成无反转。

确认只描述截至当日证据。固定首次信号时的`C[e]`：底部后收盘低于它、顶部后收盘高于它，记录该次失效，不能改写原记录。趋势延续时新拐点门槛可自然退出，当日分数下降不撤销原确认、不自动宣告失效。每日重新计算的极值可能变化，但原事件仍须保存首次值，不重复报告同一过程。

## 常见情境

| 情境 | 应有判断 |
|------|----------|
| 宽基巨量且异常净申购，国家队买入迹象强，但指数继续创新低 | 可报国家队大概率买入；底部价格仍未确认，不能凑成强底 |
| 创新高但较单次巨量峰值缩量，趋势仍向上 | 不把单峰基数效应直接计成顶部确认 |
| 主指数价格修复，伙伴不跟随 | 局部修复，未确认整体反转 |
| 主指数与至少两伙伴转向，位置满足 | 按四组算分，不要求政策/开户/ETF先表态 |
| 只有单指数完整OHLCV | 报分与缺项，不放大到100，不确认市场 |
| ETF下跌、异常净申购且巨量 | 可能国家队正在承接，抛压仍大；不因下跌否定介入，也不因此确认见底 |
| ETF巨量收涨，份额缺失且无其他方向证据 | 国家队进出方向未定，列缺项，不报无介入或已确认买入 |
| 同指数两只ETF等额反向申赎、池合计近零 | 可能迁移/调仓，不分别计新增买入与整体退出 |
| 官方表示已增持、当前ETF数据不足 | 已确认公告覆盖期增持；当前是否继续买入未知 |
| 延长到未来日期 | 原有历史评分保持不变 |
| 主指数中间缺日 | 拒绝或补齐可靠原始数据，不压缩日历 |
| 盘中短暂越过均线后收回 | 等完整日线，不用盘中价格确认 |

## 信息时点

背景中的月度数据按公布日、政策按发布时刻、份额按可得日使用，不拿当前快照补历史，也不以事后高低点解释当时本来未知的信息。
