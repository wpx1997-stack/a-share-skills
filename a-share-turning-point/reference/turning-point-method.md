# A股拐点识别 — 方法与历史复盘参考

定义主文件各信号的计算口径、历史特征与阈值依据。所有阈值来自 A 股 2005 年以来多轮大顶和大底的复盘，为待验证经验值，不是回测结论。

### 关键规律

1. **顶部**：
   - 政策转向是牛市最常见的终结 trigger（2007印花税、2015去杠杆、2021反垄断），往往领先见顶数周到数月。
   - 天量领先天价约 1—5 个月；两种量价形态最可靠——缩量顶背离（价升量缩，买盘枯竭）和放量阴线（天量收跌，机构出货）。
   - 涨跌背离（权重撑指数、个股普跌）是顶部末期结构信号，赚钱效应消退。
   - 蓝筹/主线滞涨、冷门补涨是末期标志；热门股大面积跌停+资金转向防御板块是短期见顶信号（2026-05-14）。
2. **底部**：
   - 地量领先地价；政策底通常先于市场底 1—3 个月；国家队(汇金/ETF)进场是重要信号但不保证立刻见底(2008年滞后40天)。
   - **利空出尽**：重大利空落地后市场不跌反涨（或跌后快速V型反转），说明卖盘枯竭，是强烈底部信号（2025-04-09 关税125%后V反）。
   - 国家队多主体协同（汇金+诚通+国新+社保+险资）比单一主体进场信号更强（2025-04-09）。
   - 强势股补跌是最后一跌的标志，补跌完成后卖盘力量释放完毕。
   - 杠杆/系统性风险出清（两融大幅回落、股权质押解除）是见底的必要条件。
3. **ETF 异动**：2024 年以来宽基 ETF 成为国家队主要入口。
   - 底部：ETF 放量（成交额/20日均额≥2）+ 收涨 + 份额大增 = 扫货信号（2024-09-24 沪深300ETF放量3.5倍涨4%、2025-04-09 ETF三日净流入2000亿）。
   - 顶部：ETF 放量但指数滞涨/下跌 = 派发信号。
   - ETF 单日净流入创历史纪录是极强底部信号（2025-04-08 单日1100亿）。

## 二、各信号计算口径

### T1 量价异常（两种顶部量价形态）

满足以下任一条件即触发：

**(a) 缩量顶背离**

```
PeakVol20 = max(成交额[t-19..t])
Divergence = 成交额[t] / PeakVol20 < 0.8
          且 收盘[t] ≥ max(收盘[t-19..t-1]) 或 近5日收盘均值 ≥ 近20日收盘均值
```

成交额从20日峰值回落超过20%，但价格仍在高位。含义：买盘枯竭，没人接盘。参考 2007 年天量后缩量5个月见顶、2015 年 5.28 天量后缩量滞涨。

**(b) 放量阴线（天量出货）**

```
条件1：成交额[t] ≥ max(成交额[t-19..t])  或  成交额[t] / mean(成交额[t-19..t]) ≥ 1.5
条件2：收盘[t] < 收盘[t-1]（当日收跌）
```

成交额创近20日新高（或达到均额1.5倍以上）但指数收跌。含义：放巨量不涨反跌，说明抛压远大于买盘，机构在大量出货。这是最强烈的短期顶部信号之一。

历史案例：2015 年股灾初期多次出现天量阴线；2007 年顶部附近放量滞涨后转跌；2021 年核心资产见顶时高位放量下跌。

注意区分：若放量下跌发生在长期下跌后的低位，可能是恐慌盘出清（底部信号），需结合位置判断；本信号仅在指数处于近60日高位（或涨幅较大后）时才视为顶部信号。

### T2 宽基ETF巨量异动

```
ETF_VR = ETF当日成交额 / mean(ETF前20日成交额)
条件：ETF_VR ≥ 2
方向判断：
  - ETF收涨 + 份额增加(申购) → 买盘强，可能是机构/国家队扫货
  - ETF收跌或滞涨 + 份额减少(赎回) → 高位派发
  - ETF放量下跌 → 出货信号（无论份额如何，卖盘压倒买盘）
```

宽基 ETF 放巨量是资金博弈加剧的信号。顶部常见形态：ETF 放量但指数滞涨或下跌，配合份额减少，说明机构通过 ETF 卖出成分股对冲或直接出货。需结合指数位置和份额变动综合判断，单日异动不构成结论。

### T3 估值极端

- 沪深300 PE(TTM) > 30：参考 2007 年顶部 PE~50、2015 年顶部 PE~20(结构牛，全市场更高)、2021 年沪深300 PE~17。
- 全市场 PE 分位(近10年) > 95%。
- 巴菲特指标(总市值/GDP) > 120% 为高估，> 150% 极高。

### T4 杠杆见顶

两融余额创近1年新高后连续3日回落，或融资买入额占A股成交额比例从高位(>10%)下降。2015 年顶部两融 2.27 万亿后断崖下跌。

### T5 资金供需失衡

资金流出端：
- 北向资金连续3个交易日净流出，累计净流出 > 100亿。
- 产业资本：单周重要股东净减持金额创近3个月新高，或清仓式减持公告激增。

资金需求端（抽血）：
- IPO 单月募资规模创近3个月新高，或连续多只大盘股发行。
- 限售股解禁规模创阶段新高（单周解禁市值 > 5000亿）。
- 再融资（定增、配股）密集获批。

资金供需两端同时恶化时信号更强。2007 年中石油上市、2015 年杠杆资金退潮均伴随资金面抽离。

### T6 情绪过热

满足任一：
- ST股/*ST股当日涨停家数 > 20，或低价股(<5元)大面积涨停。
- 新增投资者数量创近1年新高后，次月环比下降 > 30%。
- 新基金发行"日光基"频现(比例配售)后转冷，或单月新发偏股基金规模创阶段新高后环比下降。
- 全市场日换手率 > 5%（自由流通市值口径），情绪过热。
- 公募基金股票仓位 > 88%（"88魔咒"），加仓空间耗尽，被动卖压增大。
- 社交/媒体出现"万点论""卖房炒股"等极端乐观言论。

### T7 板块轮动末期

满足任一：
- 此前领涨主线板块近5日涨幅 < 1% 或下跌(滞涨)，同时此前长期弱势(近20日涨幅排名后20%)的板块当日涨幅 > 3% 或多股涨停（冷门补涨）。
- 前期热门股/高位股大面积跌停（>20只），同时资金流向防御板块（消费/医药/公用事业/高股息）。
- 2007 年"两桶油"涨停后见顶、2015 年垃圾股最后疯狂、2026-05-14 科技股跌停潮+猪肉白酒防御启动均属此类。

### T8 技术破坏

- MACD(12,26,9) 在零轴上方死叉，且绿柱连续放大。
- 或指数收盘跌破20日均线，且当日成交额 > 前5日均额(放量破位)。

### T9 政策转向

货币政策或监管政策出现明确收紧信号，是 A 股牛市最常见的终结 trigger。满足任一：

- **货币政策转向**：央行加息、上调存款准备金率、公开市场操作连续净回笼、MLF/逆回购利率上调。
- **监管收紧**：印花税上调、查处场外配资/违规资金入市、IPO 大幅扩容或提速、减持限制放松、融资保证金比例上调。
- **高层表态**：监管层或高层公开提示股市泡沫风险、"防范市场大幅波动"等降温措辞。

历史案例：
- 2007 年 5 月 30 日印花税从 1‰ 上调至 3‰，垃圾股连续跌停，牛市局部泡沫破裂。
- 2015 年 6 月证监会严查场外配资，直接触发股灾。
- 2021 年反垄断、教培整顿、资管新规，终结核心资产行情。
- 2018 年 1 月金融监管收紧、资管新规预期，终结蓝筹白马行情。

注意：政策转向后市场不一定立刻见顶，可能有滞后（如 2007 年 530 后到 10 月才见顶），但政策转向是顶部最重要的预警信号之一。

### T10 涨跌背离

指数处于高位但市场内部已经走弱，权重股撑指数、多数个股下跌。满足任一：

- 指数处于近 60 日高位（或距近 60 日高点 < 5%），但当日下跌家数 > 上涨家数，且持续 3 日以上。
- 权重股（沪深300成分股中市值前 20）上涨拉动指数，但全市场超过 60% 的个股下跌。
- 指数创新高，但上涨家数占比 < 40%。

历史案例：
- 2021 年春节后：沪深300 创新高，但全市场 3000+ 只股票下跌，"赚指数不赚钱"。
- 2007 年顶部：工行、中石油等超级大盘股拉指数，二三线蓝筹已见顶回落。
- 2015 年 5 月：指数还在涨，但很多个股已经开始下跌。

涨跌背离说明市场上涨动力已集中到少数权重股，赚钱效应消退，是顶部的可靠结构信号。

### B1 地量地价

```
VolRank250 = 近1年成交额中低于当日成交额的比例
条件：VolRank250 < 10%
```

2018 年底沪市单日成交不足千亿(相对当时市场规模)、2024 年初成交低迷均为底部特征。注意地量后可能还有最后一跌(恐慌盘)。

补充：全市场日换手率 < 1% 也是地量的辅助判断（与成交额分位互相验证）。

### B2 宽基ETF巨量扫货

```
ETF_VR = ETF当日成交额 / mean(ETF前20日成交额)
条件：ETF_VR ≥ 2
方向判断：
  - ETF收涨 且 份额增加(申购) → 买盘强，国家队/机构扫货
  - ETF收涨 但 份额减少(赎回) → 可能是短线套利，持续性存疑
  - ETF放量下跌 且 份额增加 → 机构申购托底但抛压仍大
```

2024-02 沪深300ETF单日成交超190亿、净流入188亿，对应市场深V反转。2024-10 宽基ETF尾盘百亿扫货也是底部信号。

### B3 估值极低

- 沪深300 PE < 11：2024年9月沪深300 PE不足11倍，低于2005和2008年底部。
- 沪深300 PB < 1.2：2024年9月沪深300 PB 1.16，低于四大历史底部。
- 破净率 > 10%：2024年9月破净股超800只，占比超15%。
- 新股上市首日破发率 > 50%，说明市场承接力极弱，投资者情绪冰点。

### B4 股债性价比

```
ERP = 沪深300股息率 - 10年国债收益率
条件：ERP 处于近10年 > 90% 分位
```

2024年9月沪深300股息率3.36%，约为1年期国债利率两倍，股债性价比极高。

### B5 国家队进场

- 汇金/证金/国新/诚通发布增持公告(四大行、ETF)。
- 宽基ETF连续3个交易日以上净流入，累计 > 200亿。
- 保险公司公告加大权益配置。
- **多主体协同**：汇金+诚通+国新+社保+险资同时表态或行动，信号强度远高于单一主体（2025-04-09）。
- **ETF净流入创纪录**：单日净流入创历史新高（如>1000亿），是极强底部信号（2025-04-08）。

注意：政策底不等于市场底。2008年9月汇金增持，市场底在10月(滞后40天)；2015年7月救市，市场底在2016年1月(滞后半年)。需结合其他信号确认。

### B6 产业资本增持

- 重要股东单周净增持为正(或净减持金额处于近1年低位)。
- 上市公司单月回购金额创近1年新高。
- 2024年A股回购金额创历史同期新高，净减持为2007年以来最低。

### B7 情绪冰点

- 新增投资者数量同比下降 > 30%，或处于近3年低位。
- 新成立偏股型基金单只平均发行份额 < 5亿份。
- 2018年底、2022年初均出现新基金发行遇冷。

### B8 政策底

- 货币政策：降准、降息、MLF利率下调、公开市场操作净投放。
- 监管政策：印花税下调/单边征收、IPO暂停/放缓、减持新规、融资保证金比例下调、鼓励长期资金入市。
- 高层表态：重要会议明确"活跃资本市场""提振投资者信心""防范市场大幅波动"。
- 2008年9月印花税单边征收+汇金增持、2024年9月一行一局一会发布会均为政策底标志。

政策底通常先于市场底 1—3 个月。政策底出现后，若叠加估值极低(B3)、地量(B1)、国家队进场(B5)，则市场底临近。

### B9 强势股补跌完成

每轮熊市末期，最后一跌通常是前期抗跌的强势板块/白马股补跌。补跌完成后市场才见底。

判断条件：
- 前期相对抗跌的板块（近20日跌幅小于大盘的板块或个股）出现连续下跌（补跌）。
- 补跌幅度达到 15%—20% 以上。
- 补跌后市场出现企稳信号：缩量（成交额不再放大）、长下影线、或指数不再创新低。

历史案例：
- 2018 年底：前期抗跌的消费白马股最后补跌，之后 2019 年 1 月见底。
- 2022 年 10 月：前期抗跌的煤炭、石油等红利股补跌，之后见底。
- 2024 年初：前期抗跌的红利/银行股补跌，叠加流动性踩踏，之后深 V 反转。

逻辑：熊市中强势股补跌意味着最后一批坚定持有者也交出筹码，卖盘力量释放完毕，是底部的必要条件之一。

### B10 风险出清

杠杆资金或系统性风险释放完毕，市场不再有强制抛压。满足任一：

- **杠杆出清**：两融余额从阶段高点回落 > 30%，且连续 5 日不再下降（企稳）。
- **股权质押风险解除**：大量上市公司股权质押触及平仓线的风险得到纾困（地方国资接盘、大股东补充质押、股价回升脱离平仓线）。
- **流动性踩踏解除**：前期因流动性危机导致的无量跌停/千股跌停现象消失，成交额恢复正常。
- **利空出尽**：重大利空消息落地（如贸易摩擦升级、经济数据不及预期、黑天鹅事件）后，市场不跌反涨，或盘中深跌后快速V型反转收回。说明想卖的人已经卖完，卖盘力量枯竭。这是最直接的底部信号之一。

历史案例：
- 2015 年股灾：两融余额从 2.27 万亿降至 0.9 万亿后企稳，市场底在 2016 年 1 月确认。
- 2018 年：股权质押风险是核心矛盾，纾困政策出台后，2019 年 1 月见底。
- 2024 年初：流动性踩踏出清，汇金托底后快速反转。
- 2025-04-09：美国关税加至125%，盘中沪指跌超2%后V型反转收涨1.31%，典型利空出尽。

注意：风险出清是见底的必要条件，但不是充分条件，需结合估值(B3)、地量(B1)、政策底(B8)等其他信号综合判断。"利空出尽"需结合位置判断——若在高位出现利空不跌，可能只是短期反弹而非见底。

### 量比计算

```
VR_ETF = 当日成交额 / 前20个交易日成交额均值
```

阈值：≥ 2 为"巨量"(用户指定)。可同时报告 ≥ 1.5 的"显著放量"作为预警。

### 方向解读框架

| ETF涨跌 | 份额变动 | 指数表现 | 解读 |
|---------|----------|----------|------|
| 涨 | 增加(申购) | 涨 | 机构/国家队买入，买盘强 |
| 涨 | 减少(赎回) | 涨 | 套利赎回为主，持续性存疑 |
| 跌 | 增加(申购) | 跌 | 机构托底申购但抛压仍大，底部特征 |
| 跌 | 减少(赎回) | 跌 | 机构赎回卖出，卖盘强 |
| 平/滞涨 | 巨量 | 平/跌 | 高位换手或派发，顶部警惕 |

### 份额数据获取

优先通过通达信 `tdx_security_deep_info` 查询基金份额；若不可用，用 AKShare `fund_etf_spot_em` 获取实时份额，或联网查 ETF 申赎数据。份额变动需至少2个交易日对比才能判断趋势。

## 四、数据获取清单

运行时按以下顺序获取，标注每项的日期、来源和完整性：

1. **指数日K**：上证指数(000001, setcode=1)、沪深300(000300, setcode=62) 近60个交易日日线，取收盘价、成交额。
2. **宽基ETF日K**：监测池内每只 ETF 近40个交易日日线，取收盘价、成交额。
3. **指数估值**：通过 tdx_quotes(hasCwInfo) 获取沪深300 PE/PB，或 AKShare/东财。
4. **ETF份额/资金流**：优先 tdx_security_deep_info，备选 AKShare fund_etf_spot_em。
5. **两融余额**：东方财富 MCP 或 AKShare stock_margin_detail_sse（需近1年历史用于B10）。
6. **北向资金**：东方财富 MCP 或 AKShare hsgt_fund_flow_summary_em。
7. **市场宽度**：当日上涨家数/下跌家数/涨停家数/跌停家数（用于T10涨跌背离、T6情绪过热）。
8. **破净率/股息率/国债收益率**：联网公开数据或东方财富 MCP。
9. **板块涨跌幅**：主要行业/概念板块近20日涨跌幅排名（用于T7轮动末期、B9强势股补跌）。
10. **产业资本增减持/回购**：联网公开数据或东方财富 MCP（用于T5、B6）。
11. **IPO/解禁规模**：联网公开数据（用于T5资金抽血）。
12. **新基金发行/新开户数**：联网公开数据（用于T6、B7）。
13. **政策/公告**：联网搜索近期货币政策、监管政策动向和汇金/险资增持公告（用于T9、B8）。

## 五、证据完整度

| 等级 | 条件 |
|------|------|
| 高 | 10个信号中 ≥ 8个有完整数据，关键信号(量价、估值、ETF、政策)无缺项 |
| 中 | 核心信号(量价、估值、ETF)有数据，部分辅助信号(两融、开户数、IPO)缺项或用代理 |
| 低 | 核心信号缺项，或主要依赖单一数据源且无交叉验证 |

完整度仅表示数据与确认的充分程度，不代表拐点发生的概率。

## 六、情境验收

| 情境 | 必须行为 |
|------|----------|
| 指数创近20日成交额新高但收跌 | 标记 T1(b) 放量阴线触发，提示出货信号 |
| 指数创新高但成交额较峰值回落>20% | 标记 T1(a) 缩量顶背离触发 |
| 宽基ETF放量上涨且份额大增 | 标记 B2 触发，解读为买盘强 |
| 宽基ETF放量但指数滞涨 | 标记 T2 触发，提示高位派发可能 |
| ETF放量但无份额数据 | 报告方向不明，需补充份额数据确认 |
| 单日成交额巨量但为低基数恢复 | 说明基数效应，不单独触发信号 |
| 顶部触发6个+底部触发2个 | 报告顶部强信号，底部弱信号，以顶部风险为主 |
| 只有估值信号触发 | 评级为弱信号，说明估值不足以单独判断拐点 |
| 国家队进场公告但指数继续下跌 | 标记政策底，提示市场底可能滞后 |
| 低位放量下跌（非近60日高位） | 不触发T1，提示可能是恐慌盘出清，结合底部信号判断 |
| 数据缺失无法计算量比 | 如实报告数据不足，不默认触发或不触发 |
| 印花税上调或查配资等监管收紧 | 标记 T9 政策转向触发，提示顶部预警 |
| 指数高位但下跌家数>上涨家数持续3日 | 标记 T10 涨跌背离触发 |
| 前期抗跌白马股补跌15%后缩量企稳 | 标记 B9 强势股补跌完成触发 |
| 两融余额从高点回落30%后企稳 | 标记 B10 风险出清触发 |
| IPO单月募资创阶段新高+北向连续流出 | 标记 T5 资金供需失衡触发（供需两端共振） |

## 七、历史有效性说明

本 skill 的信号体系基于 2005 年以来 A 股 5 轮牛熊的定性复盘，所有阈值为经验值，**尚未完成逐日回测**。实际运行时：

- 信号共振数量(≥5)与历史拐点的对应关系需回测验证。
- 2024 年以来 ETF 成为国家队主要入口，B2/T2 的有效性需更多样本验证。
- 政策环境变化(如长效稳市机制)可能改变部分信号的领先性。
- 建议每轮完整牛熊后复盘信号有效性，更新阈值。
