# A股牛熊雷达

## 范围与原则

判断A股约20—60交易日的技术环境，每天更新短期风险；只输出整体风格与风险姿态。

- 使用A股自身历史；趋势、宽度、量能、风格、题材持续性分别观察，最后综合。
- 红利/银行强、成长弱、宽度恶化，是重要防御切换；防御可以绝对上涨，但不是所有熊市的必要条件。
- 量能必查热度、变化和价格推进效率：放量上涨/杀跌、缩量整理/弱反弹、高位放量滞涨分别解释。
- 局部强不等于整体牛，小盘强不等于炒差；反弹、试探、反转确认分开。
- 数据不足、信号冲突明确报告，不能强行归类。下列参数均待A股回测，不为匹配当天行情临时调整。

流程：数据与模式 → A整体环境 → C防御切换 → 防御覆盖 → B市场结构 → 风险姿态与切换条件。

本文件是唯一分类入口。[参考文件](reference/radar-reference.md) 仅定义计算与细分：计算读第一、二节；题材读第三节；阶段/修复跟踪读第四节；验证读第五节。按需读取，不另建评分体系。

## 数据与执行预算

| 项目 | 默认范围与用途 |
|------|----------------|
| 指数日K | M/G/D/L/S成分最近30交易日，计算近期收益 |
| M周/月K | 30个完整周、24个完整月，观察中长期趋势；未完成周期单列 |
| 两市成交额 | 90交易日，计算量比、三段20日均额及近90日热度排名 |
| 市场宽度/极端涨跌 | 最近30日现成统计，优先B20/B60、涨跌家数、涨跌停与下跌扩散 |
| 题材生态 | 40交易日的联动、接力、次日反馈、持续性、轮动、负反馈摘要 |
| 按需增强 | 辅助指数周/月K、群体成交额、精确均线、年度分位、融资/估值；不作默认全量获取 |

执行：先检查通达信MCP/东方财富MCP/AKShare实际能力，选一个主源；冲突时补查第二源。优先工具侧计算、返回摘要与关键异常日，有缓存则增量更新。MCP不支持摘要时限制范围；不默认打印完整K线、逐股拉全A历史、三源重复查询或获取300日日线。缓存和过滤能力必须实际存在。

收盘用最近完整交易日；盘中标临时。所有数据注明日期、来源与统计范围，滞后项单列。默认成交额为官方沪深A股总额，宽度为沪深非ST有效样本；与M覆盖及北交所的范围差异注明。

## 符号与模式

- M=中证全指000985；G=创业板指/科创50/国证成长399370；D=中证红利000922/银行881155；L=沪深300/中证500；S=中证2000。组合以日收益等权合成；红利、银行各自表现另列。
- Rn=最近n日收益；B20/B60=站上对应日均线比例；后缀`_5`=5日均值；ΔB20_n=相对n日前变化（百分点）。
- 趋势锚优先现成MA60摘要，否则WMA13完整周代理；长支撑优先MA120/250摘要，否则MMA6/12完整月代理。B_mid优先B60，缺失用B20代理。代理不冒称精确日线指标，模式变更重评确认计数。
- RS/DRS/GDS分别为G/M、D/M、G/D的5/20日比值收益。看符号、幅度与持续性；年度分位仅可选，三者不独立计票。
- VR1=当日/前20日均额；VR5=近5日/此前不重叠20日均额；VR20=近20日/此前20日均额。Vrank90比较当前与前89日，只代表近90日热度。

缺项按指标分别处理：M趋势或B20关键记录缺失不能确认整体环境；仅缺B60/年度分位可用上述轻量模式；缺题材数据仅阻断题材确认。未知不当不成立，连续确认遇缺失中断；有已知风险仍可防御。

## A：整体牛熊

T_up/T_down：最近5日中≥3日M分别高于锚×1.01/低于锚×0.99，且锚斜率分别>0/<0；其他为趋势待确认。

| 原始候选 | 条件 |
|----------|------|
| 牛 | T_up且B_mid_5≥50%、B20_5≥40% |
| 熊 | T_down且（B_mid_5<40%或B20_5<30%）；或量价破位Q_break |
| 震荡 | 关键数据完整、以上均不满足；不是缺数据的兜底标签 |

常规新分类连续3日才替换旧分类；最近20日曾确认熊市、或该背景无法核验时，升级牛市需连续10日。未完成确认保留旧分类并标待确认；无旧状态则报告候选。使用已有状态/记录，不为重建默认扩大历史。风险覆盖当日生效，不等待牛熊切换。

## 量价与C防御切换

信号公式见参考第二节：

| 信号 | 核心含义 |
|------|----------|
| V_shrink | 持续缩量，不是单日成交冷 |
| V_expand | 异常放量，同时核对是否低基数恢复 |
| S_break | 重要支撑持续失守，区分精确日线与月线代理 |
| Q_break | S_break且V_shrink且R20(M)<0且B_mid_5<50%，强化阶段性熊市判断 |
| V_stall | 近前高放量却推进不足；宽度受损时防御，不断言已知最高点 |
| V_repair | 下跌背景下放量上涨且宽度修复，出现战术试探机会 |

C_actual（防御实际占优）=DRS20>0且GDS20<0。
C_def（防御持续强化）=最近5日≥3日C_actual，且DRS5>0、GDS5<0，并满足DRS20≥2%或GDS20≤−2%。

成长占优=RS20>0且GDS20>0；其他混合/均衡。结合绝对收益区分防御上涨与抗跌：D/G都涨且宽度改善，不因红利强判熊；都跌则防御领先不代表安全。防御组内部背离需注明。

## B：题材炒作与结构性牛市

正式结构标签为“题材主导的结构性行情”，描述局部持续上涨，不改变A大类。题材联动与延续按参考第三节确认；单日热闹只报“题材活跃”，缺数据报“未验证”。不设缩量或成长跑赢的统一入口。

广泛趋势=R20(M)>0、B20_5≥60%、B_mid_5≥50%，且R20(L)/R20(S)均>0。

主结构按优先级选：

1. 防御覆盖成立：有局部活跃→局部题材活跃（整体防御）；否则C_actual→防御主导；否则普跌/弱势分化。
2. 无覆盖：广泛趋势→已确认结构性题材行情→题材活跃→零散投机/退潮→分化。

广泛趋势伴题材联动可附“题材轮动”。零散投机需跟随不足与负反馈证据，不能仅靠大小盘或行业分散判断。

## 风险姿态与战术试探

**防御覆盖**：下列任一成立即防御；重复证据不计多票。

| 风险 | 条件 |
|------|------|
| 整体弱势 | 已确认熊市或当日熊候选成立（含Q_break） |
| 广度脆弱 | B20_5<30% |
| 防御切换 | C_def且R20(G)<0，且（B20_5<50%或ΔB20_10≤−10百分点） |
| 急性风险Q_acute | R5(M)≤−5%且当日B20≤20% |
| 滞涨风险Q_stall | V_stall且（ΔB20_10≤−10百分点或B20_5<40%） |

先定基础姿态，再检查附加战术机会：

| 环境 | 姿态与大体思路 |
|------|----------------|
| 覆盖成立 | 防御；局部热闹不改变基础姿态 |
| 牛市确认+广泛趋势+无切换待确认/趋势受损预警 | 进攻，以趋势延续为主 |
| 结构性题材确认+无覆盖+无切换待确认 | 局部进攻，以题材博弈为主 |
| 其他/关键风险条件未知 | 试探或观望，列出待确认项 |
| 核心数据不足 | 暂无法判断，可报告已知风险 |

V_repair成立且Q_acute/Q_break/Q_stall明确不成立、当前信号未失败，可在基础防御下附“放量试探”。按参考第四节跟踪承接、有效期和失败；不必等牛市确认才识别机会，也不把试探写成全面进攻。子阶段按参考第四节细分，不强行匹配。
