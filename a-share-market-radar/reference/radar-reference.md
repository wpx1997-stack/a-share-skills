# A股牛熊雷达 — 计算与细分参考

只定义主文件所用指标、信号与细分；整体分类和风险优先级以主文件为准。

## 一、计算与口径

### 样本与数据

- 日期均为交易日；历史判断只用当时已完成的日/周/月记录。缺值不填成0收益，样本排除与滞后日期注明。
- 总成交额用官方沪深A股总额；宽度默认沪深非ST、可交易且具备对应均线记录的样本。M覆盖含符合条件的北交所等证券，范围差异说明；北交所单列。提供者口径不同则注明，不静默混算。
- 个股均线/收益用一致复权；涨跌停按当日实际规则与收盘封板统计，剔除无涨跌幅限制日。历史验证用当时股票池、成员及交易状态。
- 881155银行指数须核验提供者，替代代码明确记录。组合内部重叠不能视为独立证据；群体成交额按成员去重，不能相加重叠指数成交额。

### 收益、广度与量能

```text
r_i,t=P_i,t/P_i,(t−1)−1
r_X,t=成分指数日收益的等权平均；X_t=X_(t−1)×(1+r_X,t)，初值100
Rn(X)=X_t/X_(t−n)−1
RSn=(G/M)_t/(G/M)_(t−n)−1；DRSn、GDSn对应D/M、G/D，n=5或20
1+GDS20=(1+RS20)/(1+DRS20)
Size20=R20(S)−R20(L)，单位百分点
Bn=收盘>对应MAn的有效样本比例；Bn_5=近5日均值
ΔB20_n=B20_t−B20_(t−n)，单位百分点
A/D_5=近5日上涨家数总和/下跌家数总和；平盘单列
Base20_t=mean(V_t−20..V_t−1)
VR1=V_t/Base20_t
VR5=mean(V_t−4..V_t)/mean(V_t−24..V_t−5)
VR20=mean(V_t−19..V_t)/mean(V_t−39..V_t−20)
Vrank90=100×[count(V历史<V_t)+0.5×count(V历史=V_t)]/89
```

V历史为前89日；三段20日均额取t−59..t−40、t−39..t−20、t−19..t。分母0则未知；A/D下跌家数为0标极端普涨，双零为无有效样本。

30日收盘支持当日与近5日R20、20日前高；量能持续缩量需至少30日、VR20需40日、三段均额需60日，默认90日足够。仅缺热度排名不阻断量比判断。

默认指数均用价格口径；全收益比较须全组一致，不能混入红利分红再投资收益。相对收益正负与历史排名分开：负收益的高排名仍是跑输。年度排名仅可选，以前250个有效指标值计算（当前日需至少271日日线预热），不足即省略，数据留工具侧。

### 固定模式

| 项目 | 精确摘要模式 | 缺失时的代理 |
|------|--------------|--------------|
| 趋势锚 | Anchor_d=MA60_d；Slope=MA60_t/MA60_(t−10)−1 | Anchor_d=当日已完成最近周的WMA13；Slope=该WMA13/两完整周前WMA13−1 |
| 长支撑 | MA120/MA250的近期值与10日斜率 | 当日已完成最近月MMA6/MMA12；斜率比较前完整月 |
| B_mid | 近期记录齐全的B60 | 整段B20，标短期宽度代理，不重复计票 |

周/月均线以对应完整周期收盘计算。每天使用当时可得的锚判断越线，不能用后来周五值回填周一。精确摘要优先，不能按结论选模式；变模式重评状态。周/月代理不等于日MA60/120/250。

周线报告WMA13斜率、高低点结构；月线报告MMA6/12位置、MMA6斜率及近3月高低点。周线修复但月线弱标周期冲突，不否定所有日线试探。只有当前宽度、无历史时不能编造均值或变化率。

## 二、量价信号

所有阈值为未回测默认值。成交额衡量活跃，不等于净流入；结合价格、广度和位置解释。

| 信号 | 定义 |
|------|------|
| V_shrink | VR5≤0.8且最近10日≥7日VR1≤0.9 |
| V_expand | VR1≥1.5或VR5≥1.3 |
| S_break | 任一所用长支撑线上，近5日≥3日日收盘<当时支撑×0.99；代理只称月线支撑失守 |
| Q_break | S_break且V_shrink且R20(M)<0且B_mid_5<50% |
| V_stall | High20=max(M_t−20..M_t−1)；0.97×High20≤M_t≤High20、R5(M)≤1%，且（VR5≥1.3或近5日≥2日VR1≥1.5） |
| V_repair | 近20日曾确认熊市或T_down，且V_expand、R5(M)>0、当日B20≥30%、ΔB20_5≥10百分点 |

Vrank90与三段均额校验低基数恢复、持续降温；高排名不指定方向。成交额受价格与样本变动影响，可用同范围换手率核对。当前等于前高不算突破；放量滞涨是预警，宽度受损才触发主文件Q_stall。

缩量反弹与缩量整理按趋势/宽度区分；放量上涨与放量杀跌按价格推进区分。局部滞涨需群体自身去重成交额与价格，不能借全市场放量确认群体顶部，也不能用局部顶部确认全A顶部。

## 三、题材炒作与结构性行情

使用40日生态摘要比较近5/10/20日及前一阶段：联动、涨停/炸板、晋级、次日反馈、持续天数、轮动及负反馈。内部分类可用当时主题；行业代理须注明跨行业局限，输出不点名赛道。

### 联动与持续性

- 固定可追溯分类，默认群体≥10有效成员，剔除ST/停牌/价格不足；小样本不确认。重叠主题去重，不事后按涨幅拼群体。
- **联动日**：群体上涨比例≥60%、日收益中位数>0，且≥3成员涨停或涨幅≥5%（并集）。
- **活跃池**：联动群体中满足上述涨幅条件的成员，按当天固定。次日跟踪全部成员，缺失单列；只用已完成的次日结果。
- **延续良好**：近5个活跃池观察日≥3个有效；合并反馈收益中位数>0、正收益比例≥50%。反馈为活跃日收盘→次日收盘，不冒充次日开盘介入收益；重复股票×日期不是独立样本。
- **结构确认**：同一群体R10/R20成员收益中位数均>0、近5日≥3日联动、该群体反馈延续良好、近20日≥10日有效记录、无防御覆盖。收益按窗口起点成员跟踪，成员变化与缺失注明。

### 状态规则

| 环节 | 处理 |
|------|------|
| 进入 | 结构确认且非广泛趋势→题材主导的结构性行情 |
| 维持 | 近5日≥3日联动、R10中位数>0、延续良好、无覆盖 |
| 常规降级 | 任一维持条件连续3日失败→题材活跃/分化；不能自动判熊 |
| 急性退潮 | 连续3个有效活跃池次日中位数<0且正收益比例<40%，立即降级 |
| 整体防御 | 仍保留局部活跃事实，改为局部题材活跃（整体防御）；解除后重新确认 |
| 数据中断 | 题材未验证，不由它支持局部进攻；独立成立的整体趋势/防御照常判断 |

原群体退出后新群体需独立确认，不用动态替换掩盖失败；频繁轮换伴负反馈不能称持续主线。行业分散、小盘领先不足以判零散投机，需活跃个股、跟随不足和负反馈证据。

## 四、阶段与放量试探

### 子阶段（按优先级）

| 大类 | 细分 |
|------|------|
| 牛市 | 趋势受损预警→本轮确认前10日启动期→加速期→进行中→震荡期 |
| 熊市 | 磨底候选（无急性风险）→本轮确认前10日初期→主跌/弱势延续；反弹另标 |
| 震荡 | 近10日均在当时锚±3%且Slope绝对值≤1%才称箱体，否则方向待确认 |

趋势受损预警=牛市背景下（近5日≥3日B20<40%且ΔB20_10≤−10百分点）或防御覆盖。
加速期=R20(M)>0、R5(M)>0且≥R20(M)/2、B20_5≥60%、V_expand；进行中=R20(M)>0且B20_5≥50%。其余按表，不硬配成长风格。

**磨底候选**：无Q_acute且近5日未创当时20日收盘新低；以下≥3项：R5(M)≥0；ΔB20_10≥10百分点；近5日新低占比均值≤此前不重叠20日最高占比一半；近5日收盘低点高于此前20日低点。新低统计优先现成一年指标，缺失可固定20日代理并注明，前段最大值0则未知。未知不计命中，低估值/成交冷不确认底部，也不解除防御。

### 反弹与修复跟踪

熊市R5(M)>0且ΔB20_10>0可标反弹。VR1≤1、VR5≤1、ΔB20_5<10百分点为弱修复；反转升级仍只用主文件连续确认，不能额外叠估值门槛。

V_repair首次触发日记s，保存M_s、信号日前收盘M_(s−1)、Base20_s、B20_s：

| 状态 | 条件 |
|------|------|
| 候选 | 主文件允许试探；只报已知信号，候选最多3交易日 |
| 延续 | s+2以后，两完整后续日收盘均≥M_s、两日均额≥1.1×Base20_s、B20均≥B20_s−5百分点 |
| 失败/撤销 | 10日内M<M_(s−1)且ΔB20_5≤0；或Q_acute/Q_break/Q_stall成立；或连续2日B20较信号日降≥10百分点 |
| 到期 | 延续最多到s+10，期间须未失败、B20≥B20_s−5百分点、VR5≥1，否则重评 |
| 重启 | 不移动未到期信号起点；失败后新信号至少晚1交易日且M重新高于旧M_(s−1)，再检查资格 |

未满足延续不等于失败；无未来数据不能提前宣称承接成功。普通反弹失败也须观察到：曾反弹后M跌破反弹开始日前收盘且ΔB20_10<0。候选、磨底、局部题材均不自动改变整体大类。

## 五、数据状态与验证

摘要/缓存保留：截至日期、源/范围/参数版本、三种模式、收益/锚/宽度/量能、题材结构起点、确认状态与计数、近20日熊记录、修复信号/期限/失败、缺项及补查目的。使用实际可访问记录，不宣称skill自带数据库；按新增日期更新。

证据完整度：高=相关关键数据齐、确认完成、无未决冲突；中=可判断但有代理/局部缺项/待确认；低=核心缺失或关键风险未知。不是胜率。

修改后至少核对：

- 放量杀跌不因未缩量漏判；红利与成长同涨不因防御领先判熊。
- 权重撑指数但宽度差仍防御；熊市局部活跃不升级整体。
- 单日联动不确认结构牛；熊市放量修复允许防御下试探，不提前确认反转。
- 30日日线+周/月代理可运行；缺年度排名不阻断，缺关键宽度不能假判震荡。
- 未完成周/月不回填；模式变更不拼接；排名高不改相对收益符号；未知不当风险解除。

历史验证另做：按当时信息逐日重放，与同模式趋势锚+宽度基准比较未来5/20日收益分布、参与广度、下行风险、题材延续、覆盖率和切换延迟。时间划分校准/验证区间，前推及邻近参数敏感性检查，注意重叠窗口相关；不能只挑成功反转案例。本版本尚未完成历史回测。
